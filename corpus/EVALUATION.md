## 怎么读这份数字（诚实声明）

1. **100% 不代表真实准确率。** 这是 train 划分的人工最小样本，每类只有
   1 个危险样本，设计时就对齐了规则的正则行为。它证明的是「评测流水线
   本身可用」，不是规则能力边界。
2. 评测器经过负向测试：篡改标准答案后能正确产生 FP / FN 并以退出码 1
   失败，不存在恒绿问题。
3. expected.json 中声明的 taint 引擎规则（JAL-*-101）当前不参与正式计分，
   报告中如实标注「未接入」。额外的手工 smoke run 结果单独记录，不能混入 builtin 分数。

## 复现

    python corpus/tools/validate_corpus.py
    python corpus/tools/evaluate_corpus.py --strict-locations

校验器会对整个 `corpus/` 执行匿名化卫生检查，命中时只输出文件、行号和类型，绝不回显匹配内容。

## 扩产路线（按语料库规划）

1. 每类扩到 5 危险 + 5 安全/边界 → 约 150 案例，覆盖 15 个漏洞类别
2. 跨方法样本（Controller → Service → Mapper）≥ 30 个
3. 权限矩阵样本 ≥ 20 个（authz 覆盖率作为被测指标）
4. 真实项目脱敏样本（从已验证的真实 Spring Boot 项目提取最小调用链）
5. train / validation / holdout 三分（60% / 20% / 20%），holdout 只在发布前运行
